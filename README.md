# AntonioBOT 🤖

A dedicated IRC bot for tracking study hours, streaks, and focus sessions.

### Setup
1. Create a private GitHub repository.
2. Upload these files: `app.py`, `bot.py`, `storage.py`, `requirements.txt`.
3. Connect the repo to **Render.com**.
4. Create a **Web Service**.
5. Build Command: `pip install -r requirements.txt`
6. Start Command: `python app.py`

### Commands (Antonio Only)
- `!startstudy` / `!pausestudy` / `!resumestudy` / `!endstudy`
- `!dailyrec` / `!streak`
- `!tdl <text>` / `!tdl clear`
- `!snote <text>` / `!snote play-` / `!snote stop-`
- `!mystatus <study|free|off|clear>`
- `!time`
